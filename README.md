# RetkiRapsa Mobile

A cross-platform mobile application built with React Native and TypeScript.

## Features

- Modern UI with React Native
- TypeScript for type safety
- State management with React

## Getting Started

### Prerequisites

- Node.js & npm
- NPX
- React Native CLI
- Xcode (macOS) or Android Studio
- Expo CLI

### Running the App

    $ npx expo start
